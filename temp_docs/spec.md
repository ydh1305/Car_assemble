# Car Assembly 요구사항 명세서 (Spec)

> 출처: `docs/[CRA_AI] Day2_1_Agentic Engineering.pdf` pp.20–24  
> 이 문서는 리팩토링 전후 모두 반드시 충족해야 하는 불변 요구사항입니다.

---

## 1. 차량 타입 선택

사용자는 아래 3가지 차량 타입 중 하나를 선택해야 한다.

| 번호 | 차량 타입 |
|------|-----------|
| 1    | Sedan     |
| 2    | SUV       |
| 3    | Truck     |

---

## 2. 부품 선택

차량 타입 선택 후, 아래 3가지 부품 카테고리를 순서대로 선택한다.

### 2-1. Engine

| 번호 | 엔진 |
|------|------|
| 1    | GM   |
| 2    | TOYOTA |
| 3    | WIA  |

> ※ 엔진은 선택하지 않아도 된다 (선택 생략 가능).

### 2-2. Brake System

| 번호 | 브레이크 시스템 |
|------|----------------|
| 1    | MANDO          |
| 2    | Continental    |
| 3    | Bosch          |

### 2-3. Steering System

| 번호 | 스티어링 시스템 |
|------|----------------|
| 1    | Bosch          |
| 2    | MOBIS          |

---

## 3. 조합 유효성 규칙

모든 규칙은 AND 조건으로, 하나라도 위반 시 조합이 무효(FAIL)이다.

### Rule 1
- **Bosch 브레이크**를 선택한 경우, **Bosch 스티어링**만 선택 가능하다.
  - (다른 스티어링 시스템과의 조합은 불가)

### Rule 2
- **Continental 브레이크**는 **Sedan**에 장착 불가
- **TOYOTA 엔진**은 **SUV**에 장착 불가
- **WIA 엔진**은 **Truck**에 장착 불가
- **MANDO 브레이크**는 **Truck**에 장착 불가

---

## 4. 사용자 인터랙션 요구사항

| 동작 | 입력 | 설명 |
|------|------|------|
| 뒤로 가기 | `0` | 이전 선택 단계로 돌아간다 |
| 처음으로 | `0` (최종 화면) | 차량 타입 선택 화면으로 돌아간다 |
| 실행 (RUN) | `1` (최종 화면) | 조립된 차량의 스펙을 출력하고 실행 |
| 테스트 (Test) | `2` (최종 화면) | 조합의 유효성을 PASS / FAIL로 출력 |
| 종료 | `exit` | 프로그램 종료 |

---

## 5. 출력 요구사항

### RUN 실행 시
- 유효한 조합이면: Car Type / Engine / Brake System / Steering System 스펙 출력 후 "차량이 동작합니다" 출력
- 엔진을 선택하지 않은 경우: "엔진이 없습니다" + "차량이 동작하지 않습니다" 출력
- 유효하지 않은 조합이면: "차량이 동작하지 않습니다" 출력

### Test 실행 시
- 유효한 조합이면: `차량의 부품 조합 테스트 결과 : PASS`
- 유효하지 않은 조합이면: `차량의 부품 조합 테스트 결과 : FAIL` + 실패 사유 출력

---

## 6. 준수 의무

> 코드 변경(리팩토링 포함) 시 아래 항목을 반드시 검증해야 한다.

- [ ] 차량 타입 3종 (Sedan / SUV / Truck) 모두 선택 가능
- [ ] 엔진 3종 + 생략 옵션 모두 동작
- [ ] 브레이크 시스템 3종 모두 선택 가능
- [ ] 스티어링 시스템 2종 모두 선택 가능
- [ ] Rule 1~2의 조합 규칙 5가지 모두 FAIL 처리
- [ ] 뒤로 가기 / 처음으로 / RUN / Test / exit 동작
- [ ] FAIL 시 사유 출력
